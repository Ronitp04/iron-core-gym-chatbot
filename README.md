# 📌 Project Overview

**Iron-Core Bot** is an AI-powered fitness assistant integrated into a responsive web application.

It replaces traditional static workout plans with an **interactive chatbot** that provides **real-time personalized fitness guidance**.

🔗 **Quick Links:**

- 🚀 [Live Website](http://127.0.0.1:5500/project/index.html)
- 💻 [GitHub Repository](https://github.com/Ronitp04/iron-core-gym-chatbot)
