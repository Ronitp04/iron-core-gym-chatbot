#  Iron-Core Bot — Smart Fitness Assistant
AI-powered fitness assistant built using IBM watsonx Assistant for personalized workout and diet guidance.

📌 Project Overview

Iron-Core Bot is an intelligent AI-powered fitness companion integrated into a responsive web application.

The system modernizes the traditional gym experience by providing real-time personalized fitness guidance instead of static workout guides.

Using Natural Language Processing (NLP) through IBM watsonx Assistant, the chatbot understands user queries and generates customized:

Workout routines
Training schedules
Diet recommendations

The assistant interacts with users through a conversational interface, making fitness planning simpler, interactive, and accessible.
